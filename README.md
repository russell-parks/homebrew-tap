# Russell-parks Tap

## How do I install these formulae?

`brew install russell-parks/tap/<formula>`

Or `brew tap russell-parks/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "russell-parks/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
